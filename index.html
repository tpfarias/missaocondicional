    ORI chegou à estação! ✦

    Você observou cinco situações, escolheu regras e conduziu ORI até o destino.

    • Condição
      É uma pergunta com resultado verdadeiro ou falso.
    • SE
      Define a ação quando a condição é verdadeira.
    • SENÃO
      Define a ação quando a condição é falsa.
    • Decisão
      Executa somente um desses caminhos.

    Em linguagem natural: SE a bateria estiver baixa, ENTÃO recarregue; SENÃO, continue.

    if (bateriaBaixa) {
  recarregar();
} else {
  continuar();
}

    IF significa “SE” e ELSE significa “SENÃO”.

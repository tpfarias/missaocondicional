# Missão Condicional — O caminho de ORI

Jogo local para aprender decisões com **SE** e **SENÃO**. Não precisa de instalação, servidor ou conexão com a internet.

## Como abrir

Abra `index.html` diretamente em um navegador atual. Clique em **Iniciar missão**.

## Como jogar

- Mova ORI com as setas do teclado, WASD ou os botões direcionais na tela.
- Nos cinco bloqueios, observe a leitura do sensor e escolha uma regra em linguagem natural.
- Se errar, leia o que aconteceu e tente outra regra. O robô continua no mesmo ponto.
- Depois de resolver os bloqueios, conduza ORI até a estrela da estação de pesquisa.
- **Jogar novamente** restaura o mapa e o progresso.

Todos os arquivos do jogo estão neste diretório. O `index.html` contém HTML, CSS e JavaScript, sem dependências externas. O progresso dura apenas enquanto a página está aberta.
